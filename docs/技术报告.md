# 技术报告：数学论文可验证重放审计器

仓库 `HWS-math-paper-replay-auditor`。基准日 **2026-10-18**（v0.1.1 修订）。

本报告对应 plan/01 §三 第 3 项"技术报告"。

---

## 一、LaTeX 结构解析（模块①）

**输入**：arXiv e-print 整包（`.tar.gz`）或本地 `.tex` 项目目录。
**输出**：`PaperStructure`（sections / equations / theorems / lemmas / proofs / tables /
refs / labels / packages）+ 未覆盖清单 + 解析覆盖率。

| 纪律 | 实现 |
|---|---|
| 不承诺 100% | 宏包无穷，只声明覆盖度；`unrecognized_envs` / `unrecognized_macros` 如实列出 |
| 不得静默丢弃 | 未识别环境进清单，下游不得把"没解析到"当成"论文里没有" |
| 自定义宏 | 需显式声明映射，未声明的宏不参与重放 |
| 编码 | 只按 UTF-8 读，非 UTF-8 报错不猜测 |

**覆盖率口径**：分母 = 检出的正文环境/宏数，分子 = 成功归类的数量；报告同时给两者。

---

## 二、符号断言重放（模块②）

逐条重放等式/不等式/极限/求和/积分/递推，判定三级：

| verdict | 含义 |
|---|---|
| `ok` | 相邻步等价且合法 |
| `invalid` | 确证错误，附最小反例 |
| `undecidable` | 引擎能力外（**不得**与 invalid 混同） |

实现要点：`sympy.parsing.latex` + `antlr4-python3-runtime`（**版本必须 4.11.x**：
sympy 的 `_parse_latex_antlr` 内部硬校验，放宽会让 `parse_latex` 抛 ImportError
并**静默退化**为全 invalid）。因此 pyproject 钉死 `>=4.11,<4.12`，
且 PyInstaller hiddenimports 逐个点名 antlr 子模块（动态 import 静态分析看不到）。

---

## 三、数值独立复算（模块③）

**与符号路径实现独立**（mpmath/Decimal 手写求值 vs SymPy 符号化简），
防"同源错误互相印证"。三态：一致 / 不一致 / 无法复算，附偏差量化。

容差与口径**一处定义**（`core/numerical_tolerance.py`），注记与算法同源；
报告里会带出容差来源路径，便于复核。

---

## 四、量纲一致性（模块④）

确定性量纲代数（单位向量运算），三态：平衡 / 不平衡 / 不可判定。

**边界**：量纲不平衡是**强证据**（可确证公式有误）；量纲平衡**不等于**公式正确
（必要非充分，K11）。未标单位时标 `undecidable` 并说明"缺单位标注"，不猜测。

---

## 五、依赖图完整性（模块⑤）

检出三类结构问题：悬空引用（`\ref` 指向不存在的 label）、幽灵 label（定义未引用）、
依赖断链（定理→引理链断裂）。

**幽灵 label 仅为结构性提示，不是确证错误**（K14）——它可能只是排版习惯。

---

## 六、基准（模块⑥）

18 个合成样本（五类植入错误 ×3 + 三类干净 ×3），真值台账只存 `input + expect`，
出现 `observed` 即门禁红。指标：检出率 ≥95%、误报率 **0**、解析覆盖率如实报告。

覆盖度分母反射自代码常量（新增错误类型而无用例 → 生成器报错），
堵死"悄悄做小分母"。

---

## 七、桌面应用（v0.1.1 新增实现）

| 项 | 落点 |
|---|---|
| 主入口 | `auditor.exe` / `python -m auditor.gui.main_window` |
| 主控件 | 路径输入 / 浏览 / 开始审计 / 导出报告 |
| 接到业务函数 | `gui.pipelines.audit_paper()` / `export_all()` |
| 断言 | `tests/test_gui_controller.py` 13 条（控制器 7 + 接线 4 + 打包 2） |
| 产物 | Release 附件 `auditor.exe`（含 PySide6） |

**为什么拆 pipelines**：窗口不可在 CI 无显示器环境跑，但"按钮有没有接线""导出真的写文件"
必须机械化验证。故业务逻辑全部下沉到零 Qt 的 `pipelines.py`；
`auditor.exe --selftest` 与测试走**同一条**链路（解析→四引擎→报告→三格式导出）。

**依赖缺失语义**：无 PySide6 时窗口模式 exit 3；`--selftest` 走零 Qt 路径仍可跑。

**导出格式**：Markdown（人读）/ JSON（机读，`sort_keys` 保证逐字节可复现）/ HTML（单文件 0 外链）。

## 九、已知边界

- 解析覆盖度受限（宏包/自定义宏），未覆盖项如实登记，不静默丢弃；
- `undecidable` 不等于正确，只是引擎能力外；
- 量纲平衡非充分条件；幽灵 label 非确证错误；
- 模型开关默认关；模型**从不参与数值结论**；
- 真实论文回归集只登记 arXiv id 与本地解析产物，不随仓分发全文。
