### 1.2 分层与单向依赖

```
Presentation → Orchestration → Engine → Data
                    ↑
              LLM Bridge (可插拔)

规则：
- Presentation 层不得 import Engine 内部模块（只通过 Orchestration）
- Engine 层不得 import Presentation 层
- Engine 层不得 import LLM Bridge（LLM 是可选降级）
- Data 层不得 import Engine 层
- LLM Bridge 只被 Orchestration 层调用
```

## 三、技术选型

### 3.1 核心依赖

| 依赖 | 版本 | 用途 | 锁定理由 |
|---|---|---|---|
| Python | 3.8+ | 运行环境 | 底线 3.8（本机 3.8.8-64） |
| SymPy | >=1.12 | 符号重放 | 纯 Python，随 exe 内嵌 |
| mpmath | >=1.3 | 数值复算 | 与 SymPy 独立路径 |
| pydantic | >=2.0 | 数据验证 | 结构树/断言模型 |
| PySide6 | >=6.6.3.1,<6.7 | GUI | 3.8 上限（6.7+ requires-python≥3.9） |
| PyInstaller | >=6.22.3 | 打包 | 打 GUI 必须 ≥6（5.x 确定性崩） |

### 3.2 不引入的依赖

| 排除项 | 排除理由 |
|---|---|
| Flask/FastAPI | 本期不做 Web 面板 |
| SQLAlchemy | 数据存 JSON，不引入 ORM |
| Redis/Memcached | 无服务端需求 |
| Docker | 本期不容器化 |
| TensorFlow/PyTorch | 模型权重不随仓分发 |

### 3.3 编码纪律

**K49：所有入口 `_ensure_utf8_stdio()`**

```python
# src/auditor/__init__.py
import sys

def _ensure_utf8_stdio():
    for stream in (sys.stdout, sys.stderr):
        if stream.encoding != "utf-8":
            stream.reconfigure(encoding="utf-8")
```

- 主 CLI、GUI、tools/ 下每个脚本都调用
- 测试里用 `TextIOWrapper(BytesIO(), encoding="cp1252", errors="strict")` 复现

## 四、类型定义

### 4.1 核心数据结构

```python
# src/auditor/core/types.py
from pydantic import BaseModel
from enum import Enum
from typing import List, Optional, Dict, Any

class Verdict(str, Enum):
    OK = "ok"
    INVALID = "invalid"
    UNDECIDABLE = "undecidable"

class PaperStructure(BaseModel):
    paper_id: str
    sections: List[Dict]
    equations: List[Dict]
    theorems: List[Dict]
    lemmas: List[Dict]
    proofs: List[Dict]
    tables: List[Dict]
    refs: List[Dict]
    labels: List[Dict]
    packages: List[str]
    unrecognized_envs: List[str]
    unrecognized_macros: List[str]
    coverage: float

class ClaimResult(BaseModel):
    claim_id: str
    claim_type: str
    verdict: Verdict
    evidence: str
    steps: Optional[List[Dict]] = None
    counterexample: Optional[str] = None

class AuditResult(BaseModel):
    paper_id: str
    claims: List[ClaimResult]
    summary: Dict[str, int]  # verdict counts
    coverage_report: Dict
```
