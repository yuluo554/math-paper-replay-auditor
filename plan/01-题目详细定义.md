# 模拟项目题：数学论文可验证重放审计器

> **性质**：自拟模拟项目题（**不参赛**，成果发布 GitHub 公开仓库）。交付形式为 **桌面应用 + CLI 双形态**（PySide6 + PyInstaller exe，GitHub Release 附安装包），**审计核心离线即用、零模型依赖**；模型接入为可插拔显式开关。
> **目标产出**：GitHub 公开仓库（本地目录 `HWS-math-paper-replay-auditor`，`HWS-` 为本批命名标签；仓库纯净名 `math-paper-replay-auditor`）。
> **版本史**：

> - **v2（2026-10-18 修订）**—— 回访发现"桌面形态是占位空窗口、声明的 5 个附件只传了 2 个"，
>   据实订正：① 桌面应用**真实现**（审计/断言表/三格式导出 + `--selftest` 零 Qt 全链路 + 13 条测试）；
>   ② 补齐 §三 实物（技术报告、演示 GIF、两份 demo HTML）；③ 补 LICENSE；④ plan/00 台账与索引状态回填。
> **定位宣言**：LLM 聊天能"读"论文，但不能**逐条程序化重放并留下证据**。本工具把 arXiv 论文的 **LaTeX 源码整篇**吞入，程序化**重放**其中的数学断言——符号推导逐步重演、数值断言独立复算、量纲一致性核查、定理依赖图完整性审计——输出逐条证据与三级判定。**复现危机时代，论文的数学断言应当是可复算、可复现、可回溯的对象**；LLM 聊天给不了持久状态、可复算证据与批量回归，本工具是论文数学断言的审计台。

## 一、项目介绍

**痛点**。数学与理论物理/工程论文的断言（公式推导、数值算例、量纲关系、定理依赖）极少被独立复算。现实中三类问题反复出现：**推导跳步或有误**（审稿人难逐行核）、**数值算例与公式不符或无法复现**（复现危机）、**符号与量纲不一致**（工程论文尤甚）、**依赖链断裂**（引用了不存在的定理/引理编号）。现有工具各管一摊：公式抽取只管抽、量纲检查只管量纲，**没有任何工具把"论文里的数学断言"当成可重放对象逐条复算并留证据**。

**为什么现在**。①**长上下文第一次够用**：openPangu-2.0-Flash 原生 **512K 上下文**，且压缩 MLA KV 在满上下文仅约 **12GB**——整篇论文（含附录、证明、算例表）可**不切块**地送入；②**工具增强推理成熟**：该模型官方基准 AIME 2026 93.3，**接上 Python 后升至 98.1**，正是"把自然语言推导转成可执行验证脚本、由确定性引擎复核"所需的形态；③**符号引擎成熟**：SymPy 可对可符号化断言做确定性重演。

**开源空白**（带检索式，基准日 2026-10-15）：

| 检索式（GitHub repo 检索） | total_count | 结论 |
|---|---|---|
| `arxiv latex math extraction verification` | **0** | 空白 |
| `arxiv paper numerical consistency check` | **0** | 空白 |
| `latex paper proof step checker` | **0** | 空白 |
| `math paper replication tool` | **0** | 空白 |
| `paper claim verification math` | **0** | 空白 |
| `paper equation consistency` | 1 | 无关（论文配套 MATLAB 源码） |
| `openpangu-2.0` | 4 | 2.0-Flash 相关仅两个推理引擎仓库，**零应用层** |

**软论据（辅助，不与硬论据并列）**：邻近件存在但均为单点——`HansBug/arxiv-bbox-pipeline`(0★，仅抽图/表/公式 bbox)、`kyal102/unitgate`(9★，量纲检查)、`narinzar/dimensional-consistency-checker`(0★，LLM 辅助量纲)、`vishk23/arbiter`(0★，多智能体+Z3 验论文论断)。**"论文数学断言重放 + 逐条证据 + 公开基准"的闭环不存在**。

## 二、任务要求

> **首期范围限定**：首期实装 6 个模块（①–⑥），其余列扩展项（§六）。共用工程底座：**论文结构树 + 断言模型 + 三级判定语义 + 证据链 + 合成论文植入真值基准**。

### 1）LaTeX 源码摄入与结构解析

- **输入**：arXiv e-print 整包（`arxiv.org/e-print/<id>`，gzip）或本地 `.tex` 项目目录。
- **输出**：**论文结构树**（section / equation / theorem / lemma / proof / table / ref / label）+ 宏包依赖清单 + 解析覆盖率报告。
- **引擎**：确定性 LaTeX 解析器（零模型）；宏包/自定义宏处理可挂"模型辅助归一化"开关（默认关）。
- **确定性纪律**：**宏包无穷，只声明解析覆盖度，不承诺 100%**；未识别环境/宏一律登记进"未覆盖清单"（**不得静默丢弃**——静默丢弃会让下游把"没解析到"当成"论文里没有"）；自定义宏需显式声明映射，未声明的宏不参与重放。

### 2）符号断言重放

- **输入**：模块①结构树中的可符号化断言（等式/不等式/极限/求和/积分/递推）。
- **输出**：逐步 verdict = `ok` / `invalid` / `undecidable`，`invalid` 附**最小反例**。
- **引擎**：SymPy 重演推导链（相邻步等价性/合法性）。
- **确定性纪律**：**`undecidable`（引擎能力外）与 `invalid`（确证错误）必须分级**，不得虚高判定；每类断言登记能力覆盖度；重放必须可复跑（同输入同结论）。

### 3）数值断言复算

- **输入**：论文数值表、算例、参数点。
- **输出**：独立实现重算结果 vs 论文所报数值，三态判定（一致 / 不一致 / 无法复算）+ 偏差量化。
- **引擎**：**与符号路径实现独立**的数值重算路径（防"同源错误互相印证"）。
- **确定性纪律**：**容差与数值口径一处定义**（落 `plan/02` 唯一定义点），注记文本与算法同源；数值断言不采信符号路径的自证。

### 4）量纲一致性审计

- **输入**：物理/工程类论文的公式（符号 + 单位标注）。
- **输出**：每条公式的量纲平衡判定（平衡 / 不平衡 / 不可判定）+ 证据（各项量纲展开）。
- **引擎**：确定性量纲代数（单位向量运算）。
- **确定性纪律**：**论文未标单位时不猜测**——标 `undecidable` 并说明"缺单位标注"；量纲不平衡是**强证据**（可确证公式有误），但量纲平衡**不等于公式正确**（报告须声明此边界，防过度推论）。

### 5）定理依赖图完整性

- **输入**：模块①的 label / ref / 定理-引理-证明结构。
- **输出**：**悬空引用**（引用了不存在的 label）、**幽灵 label**（从未被引用的定理）、**依赖断链**、依赖图拓扑（可导出 HTML，0 外链）。
- **引擎**：确定性图算法。
- **确定性纪律**：编号重排/引用对账**可复跑且一致**；"幽灵 label"仅为提示（论文可不引用某引理），报告须区分"结构性可疑"与"确证问题"。

### 6）内置评测基准（旗舰，零模型依赖可离线复跑）

- **输入**：合成论文 LaTeX 生成器产出的**带植入错误**的论文集 + **预置模型输出快照**（用于"模型辅助归一化"路径的离线回归）。
- **输出**：指标表——各错误类型**检出率**、**误报率**（干净论文被判为有问题 = 误报，**0 优先**）、解析覆盖率、复算一致率、依赖图完整率。
- **引擎**：基准 runner（零模型）。
- **确定性纪律**：
  - **真值来源 = 程序化植入**（生成器知道错误在第几个公式/哪一行），**真值库只存输入与期望，观测运行时实喂引擎实算**；
  - **植入错误五类白名单**：`dimension_mismatch`（量纲不一致）/ `illegal_derivation`（符号推导非法步）/ `numeric_mismatch`（数值断言算错）/ `dangling_ref`（label·ref 悬空）/ `dep_chain_break`（定理依赖断链）；
  - **真实论文回归集**：选公开勘误/撤回论文，**只存元数据（arXiv id、版本、勘误说明引用）与本地解析结果，不随仓分发全文**；
  - 覆盖度口径：按五类错误各设**最低覆盖项**并写进 manifest；**新增错误类型而无用例 → 生成器直接报错**，堵死"悄悄做小分母"。

## 六、边界与非目标

- **不做**：论文全文再分发（**只存元数据与本地解析结果**）；论文写作/润色；查重；AIGC 检测（**与系列⑪文献审计工作台撞域，不越界**）；文献著录格式审计（同上）；对论文作者的评判。
- **确定性纪律（口径）**：所有判定必须可离线复跑且同输入同结论；**模型接入是可插拔显式开关（OpenAI 兼容端点 / llama.cpp server / omni-infer），默认关闭，不随包分发模型权重**；审计核心（解析/重放/复算/量纲/依赖图/基准）为纯确定性、零模型依赖；预置快照使指标不依赖当场跑模型。
- **判定边界**：`undecidable`（引擎能力外/缺标注）与 `invalid`（确证错误）**必须区分**；**量纲平衡不等于公式正确**、**未检出错误不等于论文无误**——报告强制声明；LaTeX 解析覆盖度如实报告（未覆盖清单不得静默丢弃）。
- **免责红线**：审计结论为**提示**，不构成对论文正确性、作者或期刊的评判；最终以原文与正式勘误为准。
- **隐私红线**：全本地存储、零上传；模型开关开启时仅发送用户选中的论文片段，设置页明示。
- **品牌隔离**：不复制姊妹项目代码；文档不提及其余项目的业务领域。
