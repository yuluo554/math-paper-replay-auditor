## 一、测试分层

### 1.1 分层架构

```
Layer 1: 单元测试（tests/unit/）
  - 每个模块独立测试
  - mock 外部依赖
  - 覆盖率目标：≥ 80%

Layer 2: 集成测试（tests/integration/）
  - 模块间交互测试
  - 解析 → 重放 → 报告 全链路
  - 使用合成论文样本

Layer 3: 基准测试（tests/benchmark/）
  - 基准 runner 端到端
  - 探活用例
  - 指标达标验证

Layer 4: 守门测试（tests/gate/）
  - K 编号口径守门
  - 确定性守门
  - 编码守门
  - 安装面守门

Layer 5: 端到端测试（tests/e2e/）
  - CLI 完整流程
  - 真实论文回归集（本地）
  - 干净环境验证
```

### 1.2 测试计数纪律

**K23：测试计数全仓一致**

- `pytest --collect-only -q` 的收集数必须与 README 中声明的测试数一致
- 新增测试文件必须同步更新 README 与 CI workflow
- 测试计数当轮实测，不抄上一棒

## 二、退出码语义

### 2.1 CLI 退出码

| 退出码 | 语义 | 使用场景 |
|---|---|---|
| 0 | 达标 | 审计完成，无问题检出 |
| 1 | 未达标 | 审计完成，检出问题 |
| 2 | 用法错误 | 参数错误、文件不存在、格式错误 |
| 3 | 缺依赖 | 模型开关开启但模型不可达、GUI 缺 PySide6 |

### 2.2 退出码锁进测试

**K24：退出码三语义锁进测试**

```python
def test_cli_exit_codes():
    """退出码语义测试"""
    # 0 = 达标
    result = run_cli(["audit", "--input", "clean_paper.tex"])
    assert result.exit_code == 0

    # 1 = 未达标
    result = run_cli(["audit", "--input", "error_paper.tex"])
    assert result.exit_code == 1

    # 2 = 用法错误
    result = run_cli(["audit", "--input", "nonexistent.tex"])
    assert result.exit_code == 2

    # 3 = 缺依赖
    result = run_cli(["audit", "--with-llm", "--input", "paper.tex"])
    # 模型不可达时 exit 3
    assert result.exit_code == 3
```

### 2.3 退出码不混用

**K25：形态失败与行级失败给不同退出码**

- 形态失败（文件不存在、坏格式、空文件）→ exit 2，不进逐行清单
- 行级失败（某条断言有问题）→ exit 1，逐条进异常清单

## 四、失败路径测试

### 4.1 必须覆盖的失败路径

| 失败场景 | 预期行为 | 退出码 |
|---|---|---|
| 输入文件不存在 | 报错 + exit 2 | 2 |
| 输入文件格式错误 | 报错 + exit 2 | 2 |
| 输入文件为空 | 报错 + exit 2 | 2 |
| 输入文件非 UTF-8 | 报错 + exit 2 | 2 |
| 模型开关开启但不可达 | 报错 + exit 3 | 3 |
| 解析覆盖率 < 100% | 如实报告 + 不静默 | 0/1 |
| 数值复算不一致 | 报告不一致 + exit 1 | 1 |
| 量纲不平衡 | 报告 + exit 1 | 1 |
| 悬空引用 | 报告 + exit 1 | 1 |

### 4.2 失败隔离

**K30：单件异常不中断整批**

```python
def test_batch_failure_isolation():
    """批量处理中单件异常不中断整批"""
    papers = ["good1.tex", "bad.tex", "good2.tex"]
    results = []
    for paper in papers:
        try:
            results.append(engine.audit(paper))
        except Exception as e:
            results.append(AuditResult(verdict="undecidable", error=str(e)))
    assert len(results) == 3  # 三件都处理了
```

## 五、变异验证

### 5.1 守门必须证伪

**K31：新增/改写的守门要做变异验证**

```python
def test_k7_gate_mutation():
    """变异验证：故意注入硬编码容差，门必须变红"""
    # 1. 临时修改源码，注入硬编码容差
    inject_hardcoded_tolerance()
    # 2. 运行守门测试
    result = run_test("test_k7_no_hardcoded_tolerance")
    # 3. 断言失败
    assert result.failed
    # 4. 恢复
    restore_source()

def test_k17_gate_mutation():
    """变异验证：真值库注入 observed 字段，门必须变红"""
    inject_observed_field()
    result = run_test("test_k17_no_observed_in_truth")
    assert result.failed
    restore_truth()
```

### 5.2 三个"做了但没验"的无效形态

| 形态 | 描述 | 正解 |
|---|---|---|
| 阴性样本不含针 | 样本靠前缀被排除，待测逻辑空转 | 先断言样本中确实含待测形态 |
| 对照组改"测试的存在形式" | 改函数名移出收集集 | 改被断言的行为 |
| 断言张冠李戴 | `assert "xxx" in source` 证明不了函数被调用 | "我要验的是 X，断言里就只准出现 X" |
