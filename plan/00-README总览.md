| 日期 | 决策 | 结论与理由 |

| 2026-10-15 | **命名约定：目录标签改用 `HWS-`** | 用户明确要求。本批三题统一 `HWS-` 前缀，GitHub 仓库名用纯净名。**用户表态优先于系列旧惯例** |
| 2026-10-15 | **本批为"以 openPangu-2.0-Flash 为引擎"的题，引入新纪律「模型在环，但审计核心零模型可跑」** | **92B MoE 本地自举硬件门槛高（Q4 约 50GB 权重）**，任何"免安装 exe 内自带模型"的承诺都会踩**交付物可达性预检**。故：模型接入 = 可插拔显式开关，**不随包分发权重**；审计核心 = 纯确定性、零模型依赖、可离线复跑；基准 = 预置快照 + 真值台账 |
| 2026-10-15 | **选题：论文数学断言重放（本题的核心匹配点 = 512K 长上下文）** | 本题是三题中**唯一把 openPangu-2.0-Flash 架构级卖点（512K 上下文 + 满上下文 KV 仅约 12GB）变成题目亮点**的一题——"整篇论文不切块"是其工程可行性前提 |
| 2026-10-15 | **论文全文再分发边界：不随仓分发全文** | arXiv 使用条款与版权约束（⬜ 待核对条款细节）。仓库只存**元数据（arXiv id/版本/勘误说明引用）+ 本地解析结果 + 合成论文**；真实论文回归集仅登记 id 与解析产物。**这条写进题面边界与 .gitignore** |
| 2026-10-15 | **弃"论文格式/文献著录审计"与"AIGC 痕迹检测"** | **与系列⑪文献审计工作台（`10-7-thesis-audit-workbench`）撞域**——系列纪律要求新题领域脱钩。本题边界节显式写出"不越界" |
| 2026-10-15 | **弃"论文写作/润色/查重"** | 非确定性工具，LLM 聊天可直接替代，独特性拷问不过 |
| 2026-10-15 | **真值来源选"合成论文 + 程序化植入"而非"真实论文"** | 真实论文的"错误"无独立真值（除非有公开勘误）；**错误位置真值只能靠植入获得**。真实论文回归集只作"不误报"的负样本（干净论文）与少量有公开勘误的正样本 |
| 2026-10-15 | **量纲不平衡是强证据，量纲平衡不等于公式正确** | 量纲平衡是**必要非充分**条件（系数、符号、常数仍可错）。报告必须声明此边界，防用户把"量纲平衡"读成"公式正确"——**判定语义不虚高** |
| 2026-10-15 | **解析未覆盖清单不得静默丢弃** | 静默丢弃会让下游把"没解析到"当成"论文里没有"（假阴性）。未识别的环境/宏/结构一律登记并计入覆盖率分母 |
| 2026-10-15 | **数值复算路径与符号重放路径实现独立** | 同源会"同源错误互相印证"（看似交叉验证实则自证）。数值断言一律走独立重算 |
| 2026-10-15 | **基准真值库只存输入与期望，观测运行时实算** | 防"比对两个冻结字典"的假门（引擎坏掉也全绿） |
| 2026-10-15 | **误报率门槛 0 优先** | "干净论文被判有问题"会误导研究者改对为错，是最坏失败模式。样本驱动层误报率须实测；无观测通道层由 manifest 显式声明未测 |
